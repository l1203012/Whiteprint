# Cover gallery credits

The note covers are crops of famous oil paintings that are in the public
domain: every artist died more than a century ago, and the photographs are
faithful reproductions of two-dimensional public domain works, which
Wikimedia Commons marks as public domain too.

Each file is the Commons image resized to 1400 px wide and cropped to a
1400 × 560 band. The file name (without `.jpg`) is the id stored in a note's
`cover:` front matter field; keep it in sync with `CoverGallery.covers`.
